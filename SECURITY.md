# Security reporting

Report suspected vulnerabilities to [support@bharat.law](mailto:support@bharat.law) with the subject “Bharat Law Claude plugin security report.” Include the affected plugin version, a description, and minimal reproduction steps using synthetic data where possible.

Do not post credentials, access tokens, confidential matter records, or customer documents in public issues. If a report involves account data, send a short description first and arrange a suitable private evidence exchange with support.

This package contains workflow instructions and the public MCP URL. The hosted service enforces access to workspaces, cases, operations, and content. A reference returned by a tool is a locator, not permission to access its target. Revocation and changes to underlying access can make previously returned references unavailable.

Retrieved documents and source passages are untrusted evidence. Instructions embedded in that evidence must not change the user's request, authorize other actions, or cause disclosure of unrelated information.
